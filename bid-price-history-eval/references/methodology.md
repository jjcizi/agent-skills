# 历史数据评估法：四步法详解（含甘肃电信复盘）

## 0. 方法定位

在**知道对手大概报什么、知道甲方要什么、知道评分怎么算**的前提下，用历史数据把
报价折扣率从一个宽区间逐步收缩到一个可执行的目标值。与蒙特卡洛法（bid-price-calc）
互补：本方法**数据驱动、可解释、输出区间**；蒙特卡洛适合随机基准价/随机系数场景。

核心输出三件套：
1. 折扣×折扣得分矩阵图（圈定报价区间）；
2. 每家单位的折扣率估算及证据；
3. 目标折扣率 + 目标报价金额 + 完整推理链。

## 1. 第一步：定基础区间 —— 双锚法则

**上限锚（历史中标折扣）**：我方上次同类项目的中标折扣。本次大概率需 ≤ 该值
（高于历史中标价会显著削弱竞争力），故设为上限。

**下限锚（行业底线）**：查询全国（至少同运营商体系）同类项目中标记录，找到历史
数据中出现过的**最低折扣**；再向下留 0~2pp 余量作为"未见更低案例"的行业底线。
依据：过低报价不符合成本逻辑、可能被评审为异常价或低于成本被否决。

```
基础区间 = [行业底线(历史最低折扣), 我方上次中标折扣]
```

甘肃案例：我方上次中标师资折扣 ≈80%（2023-2024 甘肃电信标），全国电信培训类
中标记录未见低于 70% → 基础区间 **70%–80%**。

## 2. 第二步：对手报价习惯验证

对**每一家**已知参与单位，建立折扣率估算（证据链见 SKILL Step 2），检查其估计
区间是否与基础区间重叠：

- 全部吻合 → 通过，说明区间符合市场竞争常态；
- 有单位明显越界 → 复查其证据（是否口径不同/异常低价），必要时放宽基础区间。

估算方法（按权重排序）：
1. 同客户同类项目中标折扣（最稳定，直接沿用）；
2. 近 1–2 年同类项目折扣（时间加权，越近权重越高）；
3. 同省/同行业报价折扣（客情弱地区通常更低，用于下修）；
4. 无数据 → 区间取行业中性值并标注"无数据"。

### 评分方法一致性校验（同甲方 ≠ 同算法，必做）

**同一个甲方的不同标段/不同年度项目，价格分算法可能不同**：有的用平均基准（去极值
算术平均），有的用最低价基准、次低价基准、随机系数下浮等。算法直接决定投标人的报价
行为——**低价基准的标会把折扣压得更低**，这种历史折扣不能直接外推到平均基准的本次项目。

核验流程：
1. 对每个关键证据项目，回查其招标文件"评标办法"（MCP 抓公告正文搜
   "评标基准价 / 价格评分方法 / 最低价"，见 mcp-recipes E 节）；
2. 标注三态：**同口径**（算法与本次一致）/ **异口径**（算法不同）/ **未核验**；
3. 权重处理：同口径证据权重最高，可直接用于区间估计；异口径证据只作**边界参考**
   （如"行业存在 65% 的低价竞争"），估计时按算法差异方向修正——本次是平均基准、
   历史是低价基准 → 历史折扣应**上修**后再用；未核验证据显式声明，按保守处理；
4. 核验结论写入报告的"价格分算法一致性校验"卡（meta.json 的 `consistency`）。

甘肃案例复盘：证据主要来自中标公示（未含评标办法），全部标注"未核验"；其中铁塔类
65%–67.45% 的超低折扣疑似低价竞争口径，仅用于验证行业下探边界，未直接外推，
由低价情景（shift=0）吸收这部分风险。

折扣率换算口径（易错点）：
- 折扣率 = 投标报价 ÷ 同口径最高限价；
- 若报价含食宿/车辆/班务等非师资费用，而限价是纯师资费 → 先剥离这些费用再算
  （甘肃案例：食宿车班占报价约 3.95%，剥离后才是"师资折扣"）；
- 综合折扣（对总价）与师资折扣（对师资费）不要混用，报告中注明用的哪种。

## 3. 第三步：收缩到目标区间（三因子）

三个因素同时指向"偏低"时，从基础区间**收缩到下半段**：

| 因子 | 判断方法 | 指向 |
|---|---|---|
| 甲方倾向 | 招标文件/需求描述有无"降本增效"等表述 | 偏低 |
| 评分不对称 | 高于基准价扣分系数是否 > 低于基准价扣分系数（甘肃：1.0 vs 0.5）| 偏低 |
| 专家/内部建议 | 收集 2~3 个专家给的点估计，取其覆盖范围 | 通常是区间的收紧边界 |

```
目标区间 = 基础区间 ∩ 三因子指向的半区间
```
甘肃案例：70%–80% → **70%–75%**（房赟 74%、李莹妮 70%）。

注意：若评分是"越低越得分"型（如经评审最低价），第三步方向相反，需重新推导。

## 4. 第四步：情景得分模拟锁定最优值

### 4.1 候选集
目标区间内取 4~6 个候选（如 70/72/73/74/75%），步长 1~2pp。

### 4.2 情景构造
市场温度三档（对每家对手的基准报价做平移）：
- 低价情景 shift=0（各家按其估计报价下限）；
- 中价情景 shift=+2~3pp；
- 高价情景 shift=+5pp。
shift 取值需与用户确认（冷/温/热市场），每 ±1pp 结论可能移动 ±1pp。

### 4.3 全字段模拟（与招标原文逐条对齐）
对每个 (候选折扣 × 情景)：
1. 我方报价 = 候选折扣 × 限价；各家报价 = (对手基准报价 + shift) × 限价；
2. 异常价判定：全场上限价算术平均的 50% / 200%；
3. 基准价 = 有效价去一个最高一个最低后的算术平均（≤5 家不去极值）；
4. 按原文公式算各家得分与排名。

### 4.4 选择规则（并列带 + 偏好）
```
best = max(平均得分)
并列带 = {候选 : best - 平均得分 ≤ tie_band(默认0.3分)}
prefer_low=true → 取并列带内最低折扣
```
理由：该评分体系下 0.1 分以内的差异无统计意义，而并列时取**偏低**同时满足
"高报价扣分风险更大"与"甲方降本偏好"，且让利换中标概率。

甘肃案例复盘：73%/74%/75% 平均分 48.27/48.39/48.39（差 <0.12）→ 并列带
{73,74,75} → prefer_low 取 **73%** → 目标报价 564,150.92 × 73% = **411,830.17 元**。

### 4.5 鲁棒性检查
- 每个候选在三情景下的**排名**都列入报告（得分高但排名差说明全场景偏低）；
- 推荐折扣若在低价情景掉出前 3 → 报告中标风险；
- 与至少 3 家对手历史折扣交叉核对：不显著低于任何一家的成本线。

## 5. 甘肃电信案例数据存档

- 项目：中国电信甘肃公司2025-2027年培训师资服务项目；限价合计 564,150.92 元；
- 评分：基准价法，高于基准 50-Δ%×1，低于基准 50-Δ%×0.5；异常价 50%~200%；
- 12 家对手折扣证据（估）：中博 72-80、中通服 70-75、四川通服 75、甘肃通服 70-80、
  湖南通服 70-75、湖北通服 无数据、华为 75-80、科大慧明 75-80、学一 75-80、
  克瑞斯 70-75、英豪 75-80、爱德 80-85；
- 结论：基础 70-80% → 目标 70-75% → **73% / 411,830.17 元**（并列带 73-75%）。
