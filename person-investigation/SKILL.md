# 人物背景尽调技能

## 调研哲学

**像调查记者一样思考，兼顾系统性与适应性地完成尽调。**

执行尽调时不会机械地按预设清单逐项搜索，而是带着明确目标进入，根据每一步发现的线索动态调整方向——全程围绕「我要还原这个人的什么面貌」做决策。本 skill 的所有行为都应遵循这个逻辑。

**① 明确任务** — 用户要调查谁？目的是什么（投资尽调、合作评估、招聘背调、风险排查）？什么信息算「够了」？目的决定深度：投资尽调需要穷尽公开信息；快速了解只需核心经历和风险信号。这是后续所有判断的锚点。

**② 选择切入点** — 根据用户给出的初始线索（姓名、公司、职位、行业），选一个最可能快速定位到人的方式开始。线索丰富（姓名+公司+职位）可直接深入；线索模糊（仅姓名）则先消歧。不预设"必须从某个平台开始"。

**③ 线索追踪与校验** — 每一条搜索结果都是线索，不只是"有或没有"的二元信号。一篇报道中提到的合伙人姓名、一个 LinkedIn 页面上的前公司、一条即刻动态里的行业观点——这些都是可以追踪的新线索。同时对照①的任务目标：哪些维度已经覆盖？哪些还有缺口？信息之间是否有矛盾需要交叉验证？发现搜索方向无效时立即调整——搜索没结果不等于"还没找对关键词"，也可能是"这个人在该平台没有痕迹"。

**④ 完成判断** — 对照定义的任务目标，确认各维度已充分覆盖后才停止。但不为了"完整"而浪费代价——如果某维度反复搜索均无结果，标注"未找到公开信息"即可，不需要穷尽所有可能的关键词组合。

### 信息获取原则（两种模式通用）
- **一手信息优于二手信息**：搜索引擎是发现入口，不是证据来源。找到线索后追溯到一手来源（本人账号、公司官网、官方公告）
- **多个媒体引用同一个错误会造成循环印证假象**——三篇文章说同一件事，不等于三个独立来源，需看它们是否引用了同一个源头

### 尽调场景的信息可信度分级

| 可信度 | 来源类型 | 说明 |
|--------|---------|------|
| **高** | 本人直接产出 | LinkedIn/脉脉 本人维护的资料、个人博客、GitHub、本人署名文章、本人社交媒体发言 |
| **高** | 官方记录 | 公司官网团队页、工商登记（天眼查/企查查）、法院判决书、专利/论文数据库 |
| **中** | 权威媒体原创报道 | 36氪、财经杂志、Bloomberg 等采编的原创报道（非转载） |
| **中** | 第三方平台聚合 | IT桔子融资记录、Crunchbase 等（数据来源通常为企业自报+媒体报道） |
| **低** | 转载/二手报道 | 内容农场转载、未注明来源的自媒体文章、匿名爆料 |

**报告中标注可信度**：对关键信息（职位、融资金额、教育背景）注明来源类型。当仅有低可信度来源时，明确告知用户："此信息仅来源于 [来源类型]，建议进一步核实。"

## 工作流程

### 阶段 1：消歧与锚定

**目标**：确定唯一的调研对象。

**名称变体生成**：当输入为中文姓名时，自动生成英文的拼音变体（例，输入为张三，其英文对应为 San Zhang）进行搜索，覆盖不同平台可能使用的不同拼写方式。

**评估初始线索**：用户提供信息后，先判断是否足以唯一定位：
- 姓名+公司/职位+行业 → 线索充分，可直接尝试定位
- 仅有常见姓名 → 询问用户补充信息，或进入浅层搜索列出候选人

**浅层搜索**：目标是快速区分同名者，不是深挖
- 用姓名 + 可能的限定词（行业、城市、职位类型）组合获取信息
- 定位 3-5 个最可能的候选人，每人提供：当前身份、关键背景、信息来源
- 呈现给用户确认

**消歧失败时**：继续追问具体特征（"是做 AI 方向的吗？"、"大概什么年龄段？"），不要在不确定的情况下进入深度调研。

### 阶段 2：深度调研

**目标**：按维度系统性收集目标人物的详细信息。

**调研维度**：

核心维度（必须覆盖）：
- **教育经历**：学校、专业、学位、时间线
- **职业轨迹**：公司、职位、时间线、职责
- **创业/投资历史**：项目、融资、退出情况、投资案例
- **关系网络**：合伙人、共事关系、投资人关系

补充维度（根据任务目的和可获得信息）：
- **公开观点**：访谈、演讲、文章中的立场
- **社交媒体画像**：活跃度、内容风格、影响力
- **风险信号**：负面新闻、诉讼、争议
- **技术背景**：开源贡献、专利、论文

**线索追踪原则**：
- 每条信息都是新线索的入口——报道中提到的公司名、合伙人姓名、投资方，都可以反向搜索以获取更多信息
- 不同维度之间会互相印证：教育背景中的学校可以与论文中的机构交叉验证，职业轨迹中的时间线可以与融资新闻交叉验证
- 发现矛盾时（如两个来源给出不同的入职时间），标注矛盾并尽可能找到一手来源确认

### 并行调研：子 Agent 分治

深度调研阶段的各维度通常相互独立，鼓励通过子 Agent 并行执行。

**分治策略**：

| 适合并行 | 不适合并行 |
|----------|-----------|
| 各平台信息独立采集（LinkedIn + 天眼查 + GitHub 同时） | 需要前序线索才能继续的调研（先确认公司名，再查工商信息） |
| 多个社交媒体平台同时采集 | 消歧阶段（需要汇总判断） |
| 每个子任务需要多页浏览或深度抓取 | 单次 WebSearch 就能完成的轻量查询 |

**子 Agent Prompt 写法**：
- 如果当前环境有 web-access skill，必须在 prompt 中写 `必须加载 web-access skill 并遵循指引`
- 描述**要什么**（"获取张三在 LinkedIn 上的完整职业经历和教育背景"），不指定**怎么做**（不要写"先搜索 LinkedIn，然后点击..."）
- 避免暗示具体手段的动词（"搜索"、"抓取"），使用目标导向的动词（"获取"、"调研"、"了解"）

### 阶段 3：报告生成

**报告结构**（根据实际调研结果调整，不要为空维度强行填充）：

```markdown
# {姓名} 背景尽调报告

> 调查时间：{日期}
> 调查目的：{用户指定的目的}

## 一、人物身份

| 项目 | 信息 | 来源 |
|------|------|------|
| **姓名** | 中文名 / 英文名 | — |
| **教育背景** | 学校、专业、学位 | 来源标注 |
| **当前身份** | 职位、公司 | 来源标注 |
| **所在地** | 城市/地区 | 来源标注 |
| **核心领域** | 专业方向 | — |

## 二、完整职业经历

| 时间 | 公司 | 职位 | 关键事迹 | 来源 |
|------|------|------|----------|------|
| 2020-至今 | ZZ科技 | 创始人兼CEO | 获A轮融资XX万美元 | 36氪报道 |

## 三、创业/投资历史
（如适用，含融资轮次、金额、投资方、退出情况）

## 四、关系网络
（合伙人、共事关系、投资人关系图谱）

## 五、社交媒体画像

| 平台 | 账号/状态 | 活跃度 | 内容特征 |
|------|----------|--------|---------|

## 六、核心公开言论

按主题分类组织，每条标注来源和时间。

## 七、风险信号
（法律诉讼、负面新闻、争议事件。无则标注"未发现公开风险信号"）

## 八、人物画像总结

2-3 段文字总结：核心背景、行业地位、个人风格、当前方向。

## 九、信息缺口与建议

明确标注哪些维度未能获取到信息，以及可能的补充调研方向。
```

**报告原则**：
- 每条关键信息标注来源和可信度
- 区分"已证实"（多源交叉验证）、"单源"（仅一个来源）、"待核实"（来源可信度低）
- 对矛盾信息并列呈现，不替用户做判断
- 空维度标注"未找到公开信息"而非省略——让用户知道你查过了

## 反模式

执行尽调时避免以下陷阱：

| 反模式 | 正确做法 |
|--------|---------|
| 对每个维度都用相同的关键词模板搜索 | 根据已有线索动态构造搜索词，前序发现的信息是后续搜索的输入 |
| 搜索无结果时反复换关键词重试同一平台 | 3 次无效后判断该平台可能无此人信息，标注后转向其他平台 |
| 把多篇转载同一消息源的报道当作"多源验证" | 追溯到原始来源，判断是否真的有独立的多个信息源 |
| 为了报告"完整"而对空维度编造推测 | 明确标注"未找到公开信息"，不猜测 |
| 串行逐维度执行，一个维度完成后才开始下一个 | 独立维度并行分治给子 Agent，总耗时大幅缩短 |
| 只搜索中文或只搜索英文 | 对可能有海外背景的人物，中英文都要搜索 |

## 隐私与合规

- 仅使用公开可获取的信息
- 不进行非法信息获取
- 敏感信息（如家庭成员详情、个人住址）不主动收集，除非用户明确要求且信息为公开可得
- 报告中对信息来源透明，让用户自行评估
