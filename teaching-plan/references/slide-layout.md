# 投屏 PPT 与材料包规范（teaching-plan 的配套产物）

本文件规定教案配套产物的形态与生成方式：投屏 PPT、打印材料包、材料清单。

## 一、投屏 PPT（视觉参照 kami）

生成：

```bash
cd "教案-<课题>"
python3 ~/.codewhale/skills/teaching-plan/scripts/make_pptx.py "源文件/教案-<课题>.md" \
  -o "投屏PPT-<课题>.pptx" --title "<课题>" --subtitle "<课时>"
```

视觉取自 kami：羊皮纸底 `#F5F4ED`、唯一强调色墨蓝 `#1B365D`、衬线层次、大留白、
顶部一条墨蓝细线。16:9，标题 30pt 墨蓝，正文 16~22pt（按行数自适应），
提问框为墨蓝圆角底 + 白字。

### 标签与封面都不得暴露教学策略

PPT 是给学生看的。**不能出现机制名与教学法名称**（悬念 / 反转 / 身份 / 站队 / 盲盒 / 复盘，
以及“综艺思维”“六机制”这类词），否则等于提前告诉学生“下面要制造悬念了”，机制当场失效。

- **封面副标题**：只写班级、场合、日期这类中性信息。写成“综艺思维六机制 · 90 分钟”
  是最常见的错误（那是备课信息，不是学生信息）。`make_pptx.py` 会检测并省略这类副标题。
- **页面标签**：用**学生视角的活动语言**，例如：第一环节 · 开场 ／ 第二环节 · 读一份方案 /
  第三环节 · 分组讨论 / 第四环节 · 抽一张卡 / 第五环节 · 讲清楚 /
  第六环节 · 做选择（第 N 次）/ 第七环节 · 回到最开始 / 第八环节 · 动手写一份。

机制名只出现在教案（教师用）里。

## 二、一页只放一个问题（重要规则）

投屏页面的读者是坐在台下的学生，不是备课的老师。据此：

- **悬念、反转、站队、盲盒类环节：一次只显示一个问题。**
  一股脑把所有问题抛出去，学生只会盯着最后一句话，前面的思考被跳过。
- **需要逐条揭晓或逐轮加条件的：一页一条，用翻页推进**（教案里用块内 `---` 分段）。
  逐条出现是这些机制的命脉——答案提前露出来，悬念就失效了。
- **只有总结/回顾页才允许一次列全**（例如"今天这节课的五个要点"）。
- **提问页与情境页要分开**：情境先单独给一页（让学生进入场景），
  再翻页给问题。合在一页会让"抛问题"的时机消失。

判断标准很简单：**如果学生看到这一页就能猜到下一句话，这一页就不该存在。**

## 三、哪些内容必须投屏

| 环节要素 | 是否投屏 | 说明 |
|---|---|---|
| 悬念情境（含真实素材） | 是 | 情境单独一页；提问另起一页 |
| 反转的第一版信息（"看起来齐全"的方案） | 是 | 完整投出，让学生自己判断 |
| 反转的第二组信息（逐条揭晓） | 是 | 一条一页，或一页内用翻页逐条 |
| 身份分组表与追问 | 是 | 表格一页 + 问题一页 |
| 盲盒卡片 | 否（打印） | 卡片是实物，发给各组；投屏只给"共同问题" |
| 站队情境与四轮条件 | 是 | 情境一页，之后每轮一页 |
| 讲授要点（口诀、三个类比、四大作用） | 是 | 提炼成关键词，不投长段落 |
| 复盘提问 | 是 | 一页一句话 |
| 练习要求 | 是 | 六项要求一页列全（这是任务清单，允许一次列全） |
| 术语对照表 | 投屏可选，**必须打印** | 印在学案上比投屏有用 |

## 四、打印材料包

生成（在课题子目录内执行）：

```bash
cd "教案-<课题>"
python3 ~/.codewhale/skills/teaching-plan/scripts/make_pack.py 源文件/配套材料 \
  -o "打印材料包-<课题>.docx" --title "《<课题>》配套打印材料"
```

- **每份材料从新的一页开始**（教师直接打印即可，不用手动分页）。
- **每页填充率 88~100%**：不许挤在角落（字小、留白多），也不许溢出。
- 默认适配排版：字号约 10pt、页边距 1.4cm、行距 1.3。
- 两个排版工具（写法见 SKILL.md §5.8）：
  - `:::cards 2 h=215` —— 卡片/纸条类用多列表格排布，表格线即裁切线，`h=` 控制行高撑满页面
  - `:::gap 34` —— 文字类材料用固定空白段撑满页面
- **调参必须实测**：生成 → 转 PDF → 量填充率 → 调 `h=`/`:::gap`，反复到位。
  量的时候要把表格线和矩形算进去，只看文字会低估。
- **材料上不写任何元信息**：不要“【需打印】材料 N”“共 N 份材料”“请按《材料清单》打印”
  之类的话，**也不要页眉与页码**（默认关闭）——那些属于《材料清单》。
- 需要裁剪的卡片类材料：表格线或裁切线就是切分位置。

## 五、材料清单

单独输出一份（默认 `.md` + `.docx`），逐条列出：材料编号、名称、对应环节、
用途、建议份数、纸张（A4 / A5）、单面或双面、是否需裁剪。教师直接照单打印。

## 六、交付物组织（默认整套产出）

**全部产物放进同一个课题子目录 `教案-<课题>/`**，文件名不加“XX版”后缀。
**交付区只放 .docx 与 .pptx**：同一内容不保留 md / docx / pdf 三种格式，
Markdown 源统一收进 `源文件/`；PDF 默认不生成，除非用户明确要。

```
教案-<课题>/
├── 教案-<课题>.docx           教师用；投屏内容以黄底标出
├── 投屏PPT-<课题>.pptx        上课投屏
├── 打印材料包-<课题>.docx      每份材料一页，直接打印
├── 材料清单-<课题>.docx        照单打印
└── 源文件/
    ├── 教案-<课题>.md
    ├── 材料清单-<课题>.md
    └── 配套材料/材料N-<名称>.md
```

板书说明并入教案的“板书 / PPT 建议”节，不单独出文件。

投屏内容在教案里的标记语法：

```markdown
:::slide 环节一｜悬念开场
页面标题行
正文要点
---
（同组下一页）
提问：这一页的核心问题
:::
```
