# 综艺式课堂教学设计（六机制）

## 0. 一句话定位

把一节课当作一档综艺来"设计注意力"：不是把课堂变娱乐，而是用
**悬念 · 身份 · 反转 · 站队 · 盲盒 · 复盘** 六种机制，重排一节课的
认知节奏，让学生经历"想知道 → 需要想 → 重新想"的过程。

核心理念（贯穿始终，来自原帖）：
- 优秀课堂不是让学生觉得"老师好厉害"，而是让他在某一瞬间觉得"这个问题我以前真没想过"。
- 最好的知识，不是老师恰好准备讲，而是学生突然发现自己需要它。
- 一节课真正的结束，不是老师讲完最后一页 PPT，而是学生重新理解了第一分钟的那个问题。

## 1. 何时用 / 何时不用

**用**：用户给出一个知识点、一段教材文字、一篇课文、一个章节标题，或一份教材文档，
希望得到"怎么上"的教案、课堂流程、互动设计、教师逐字脚本。

**不强用**：只需要知识点本身讲解（那是 `university-lecture` 的场景）；
只需要出题、需要纯理论阐述、或用户明确只要传统讲授式大纲时。

## 2. 输入处理

先判断输入形态，再决定读取方式：

- **一段文字 / 一个知识点**：直接分析，无需读取。
- **文档路径**：必须真正读出全文再设计，不要凭空假设内容。
  - `.docx`：用 `documents` skill，或 `python-docx` / `textutil -convert txt`。
  - `.pdf`：用 `pdf` skill，或 `pdftotext`。
  - `.pptx`：用 `pptx` skill。
  - `.txt/.md`：直接 `read`。
- 必要时向用户确认：**学段（中学/大学/培训）、课时长度、班级规模、是否需要联网找真实案例**。
  这些缺失会显著影响设计，但若能合理默认（如"45 分钟,大学"）就先默认并在教案开头注明。

## 3. 生成工作流（按序执行）

1. **读懂内容**：确定学科、学段、课时、这一课要传达的**核心概念/结论/价值判断**。
2. **找"认知痛点"**：标出学生最容易无感、想当然、或存在直觉误区的地方——这几处就是机制切入点
   （例：医学伦理的"知情同意"、青年就业的"归因偏差"、文学人物的"价值排序"）。
3. **准备素材（可选联网）**：按 §6 用真实案例、数据、争议事件支撑。宁缺毋滥，不得编造。
4. **机制匹配**：从 §4 六机制库中选 **3~6 种**，按认知节奏排序，形成"机制地图"。
   不是每节课都必须用满六种——用哪一种要看内容需要，能省则省、用时用透。
5. **编排时间轴**：给每个环节分配分钟数，明确教师动作 / 学生活动 / 关键提问 / 过渡语。
6. **写教案**：按 §5.1 模板输出，形成完整可上课的脚本；投屏内容用 `:::slide` 标记（§5.7）。
7. **写全部子材料**：教案里提到的**每一份子文档都必须真实产出**（§5.9）——包括那些
   “作为反面教材拿给学生看”的文档（如一份看起来齐全、实际缺三项的方案）。
   教案正文不允许出现“投出一份 XXX”却没有这个文件的情况。
8. **生成配套产物**：教案 Word、投屏 PPT、打印材料包、材料清单（§5.6~§5.10）。
9. **自检 + 交付**：过 §7 校验清单，向用户报告全部产物路径与未确认项。

## 4. 六机制库（核心工具箱）

每个机制给出：**作用 → 设计要点 → 提问/操作模板 → 常见误区**。设计时直接取用。

### 4.1 悬念机制（开场，制造"非知道答案不可"的问题）
- **作用**：人的注意力被"未完成"抓住。先给一个不完整的信息，逼出疑问，再让知识成为学生自己需要的东西。
- **设计要点**：不给答案、只给场景 + 一个必须抉择的问题；信息**逐层揭示**（第二轮、第三轮再加条件）。
- **模板**：
  - "大屏幕上只有一句：___（一个未解的处境/一句判断）。你怎么办 / 你说，还是不说？"
  - 逐轮加条件："如果再补充一个信息——___，你的选择变吗？"
- **误区**：把悬念做成"猜谜游戏"却与知识点无关；只吊胃口不给落点。

### 4.2 身份机制（换位置，才能看见"立场"）
- **作用**：身份一变，观看方式就变。让学生离开自己的位置，理解"同一条事实，不同位置看到不同的世界"。
- **设计要点**：给**同一组事实**，分 4~5 个角色组；核心提问是"你们最在意的是什么"。
- **模板**：把班级分 N 组，每组一个身份（当事人 / 记者 / 平台 / 网友 / 管理者……），
  给同一份材料，5 分钟后各组回答"你最在意什么"，再问"为什么同一个人，每个人看到的不一样？"
- **误区**：分组只为热闹，最后不收敛到"立场/视角"这一层。

### 4.3 反转机制（打破快速判断与贴标签）
- **作用**：年轻人习惯在信息不完整时下判断。先让学生快速判断，再给第二组信息推翻它，训练"看见自己的结论是怎么来的"。
- **设计要点**：先给"一句话判断"→ 学生下结论 → 给第二组真实信息 → 安静 3 秒 → 追问。
- **模板**："先出现一句话：___。你觉得可能是什么原因？"→ 学生答 → "再给你第二组信息：___。
  刚才那些判断，你还保留多少？我们判断的是这个人，还是我们脑子里关于'___'的想象？"
- **误区**：反转后直接说教批评；反转信息与知识点脱节。

### 4.4 站队机制（让选择有代价，逼出真实价值排序）
- **作用**：普通讨论会退化成"正确答案表态"。给选择**逐轮加代价**，让立场被迫流动。
- **设计要点**：第一轮问喜好 → 每轮加一个现实约束（钱、年龄、家庭、时间、责任）→ 选择开始移动。
- **模板**："第一轮：你喜欢 A 还是 B？"→ 加条件"___"→ 再选 → 追问"为什么你的价值没变，选择却变了？"
- **误区**：只让学生举手表态，不加条件、不追问代价；把站队变成"站对了夸奖"。

### 4.5 盲盒机制（用随机条件改变起点，讲结构与公平）
- **作用**：随机抽取"条件卡"，让学生看见"意志"与"现实条件"如何共同决定结果。适合讲社会结构、机会公平、青年发展。
- **设计要点**：每人随机抽一张条件卡（家庭/资源/健康/负担……），面对**同一个问题**作答，再对答案的差异发问。
- **模板**：全班抽"人生卡"→ 共同问题"___，你选什么？"→ 追问"选择到底是个人意志，还是个人意志与现实条件共同完成的结果？"
- **误区**：把盲盒做成纯游戏，不落点；或把结论说成"努力无用"（正确落点是：承认结构不等于否定奋斗）。

### 4.6 复盘机制（结尾闭环，回到第一分钟）
- **作用**：综艺结尾重放前段镜头，因为人在结尾会重新理解开头。复盘决定学生能否把课带走。
- **设计要点**：开场让每个学生写下/预测一个东西，**收起来**；课中间正常展开；最后 5 分钟发回，只做对比，不考试、不打分。
- **模板**："上课第一分钟请写下你心中的'___'。"→ 课后："如果现在重写一次，你会改哪个词？"
- **误区**：结尾只说"今天我们学了三个知识点"；复盘又变成一次考核。

### 5.2 跨环节动作：写在发生的那一刻，而且要说清楚“对学生怎么说”

这是最容易漏的设计缺陷。典型错误：教案在环节七写“开场时已发小纸条”，
而**环节一里根本没有发纸条的指令**——教师照着教案走，必然漏掉。

四条要求（缺一不可）：

1. **教案开头设一张“跨环节动作提醒”表**，集中列出所有“什么时候发什么/收什么”：
   上课前、开场第 N 分钟、各环节开始时、下课后。
2. **在动作真正发生的那一节用 `★` 标出执行时机**，写清做什么、几分钟内做完。
3. **在使用它的那一节写回指**（“见环节一的 ★”），
   不要写成“已经发过了”——那是事后叙述，不是执行指令。
4. **发放类动作必须给出“教师指导语”（对学生说的原话）**，包含五件事：
   - **做什么**：写什么、填什么、选什么（把问题原文写出来，别只写“发下去”）
   - **多久**：几分钟内完成
   - **要不要署名**
   - **怎么交**：放哪、传给谁、什么时候收
   - **给一个不泄底的由头**

> **最后一条最容易漏。** 如果这份材料的真正用途是后面环节的伏笔
> （典型：开场纸条要在环节七发回做前后对比），就**不能对学生说破**；
> 但也**不能什么都不说就发下去**——学生会以为没用而敷衍，收上来一片空白。
> 给一句合理的托词即可，例如：
> “为什么写这个，今天下课前最后十分钟你们就知道了。”
>
> 常见错误：教案只写“发材料 4”，既没对学生的说明，也没对教师的提示。
> 结果教师当场不知道该怎么讲，学生不知道写来干嘛。
>
> 补充：如果这个动作**有对应的投屏页**，教师可以指着屏幕说——在教案里引用投屏页即可；
> 只有**不能投屏的**（用途需要保密，如开场小纸条）才必须写出完整的口头指导语。

同理适用于：预填表格、收回作业、分组、抽签、张贴、宣布规则。
凡是“前面做了、后面才用”的动作，都按这四条写。

#### 贯穿全课的材料（学案、任务单）

学案这类“全场都用”的材料，最常见的错误是**教案里只把它列在材料表里，不写什么时候发、
什么时候填哪一栏**——结果学生把它压在书底下，下课还是空白。

三条要求：

1. **开场就发**（不要等到用的时候才发），并在“跨环节动作提醒”表与开场的 `★` 里写明
   （含教师指导语：“先写上名字，这节课每个环节我都会提示你们填哪一栏”）。
2. **在每个用到它的环节，写清“填学案第 X 栏”**，教师照着念就行。
   例：环节二结束后写“填学案『课堂记录 1』：我第一眼判断能不能用、后来发现缺哪三项”。
3. **学案不收回**（学生自己留），它是笔记与作业载体——但要说明“带走，下次课交 / 自行复习”。

> 自查办法：把学案上的每一栏龙过一遗，能不能在教案里找到“什么时候填”的对应环节？
> 找不到的那一栏，就是学生会空着的那一栏。

#### 分组是最容易出错的跨环节动作

典型错误：环节二写着“每组发 1 份材料 1”，而分组指令到环节三才出现——
教师做到那里才发现还没分组。

两条要求：

1. **分组必须在第一次用到“组”之前完成**，并在那一步用 `★` 写出来。
   做好的时机往往是**环节二开头**（悬念开场需要安静，不宜一上课就分组）。
2. **必须给出分组方法**，不能只写“全班分 5 组”。要写清：怎么分、用多久、要不要挪座位、
   组内要不要选人。推荐两种可直接用的方案：
   - **按座位分（首选）**：前后两排为一组，6 人左右一组，全班自然分成 5~6 组。
     **不用挪座位**，1 分钟完成，且左右同学彼此熟悉，讨论不冷场。
   - **报数分（备选）**：1~6 循环报数，同号成组。适合需要打散小圈子的班，但要重新找位置，
     多花 2~3 分钟。
   同时提醒教师：**各组推一名记录员和一名发言人**，避免讨论完没人开口。

### 5.3 落点不能只有一句口号

每个环节结束时的“落点”，是知识点真正落地的地方。
只写一句漂亮话（如“章程是让所有相关方点头的东西”）是不够的——
教师拿到它不知道怎么讲、讲到什么程度，学生听完也只是感到“这句话挺好”。

**落点必须写成三行**：

1. **教师原话**：把教师要说的话写出来，2~4 句，可以直接照读。
2. **为什么这样收**：这个环节真正要让学生看到什么（1 句教学意图，教师自己看）。
3. **学生应有的反应**：出现什么反应算收口成功（1 句，可观察的具体表现）。

例：

```
- **落点**
  - **教师原话**：“刚才五组给了五份'必写项'清单。请注意，这五份没有一份是错的——
    因为它们来自五个不同的位置。章程不是一个人埋头写的作业，
    它是让所有相关方对同一件事点头的东西。”
  - **为什么这样收**：不要让学生比“谁的清单对”，而要让他们看到“立场决定关注点”。
  - **学生应有的反应**：有人开始问“那怎么把五份清单合成一张”——这就是下一环节的引子。
```

> 落点不是总结知识点（那件事留给板书），而是**把学生刚经历的事，翻译成一句他们能带走的话**。
> 所以它必须贴着刚刚发生的活动说，而不是脱开情境去念定义。

### 5.4 时间分配建议
- 45 分钟：悬念 3-5 / 主体 2 个机制共 25-30 / 复盘 5。
- 90 分钟：可完整用 5-6 种机制，每个机制间留出小组讨论与全班收敛。
- 原则：**开场先于答案、复盘必须闭环**；宁可少用一个机制，也不要塞满。

### 5.5 机制组合参考（按内容类型）
原则：**复盘为必选**，其余机制按内容需要增减；开场优先用悬念（见 §5.4）。
- 价值/选择类（思政、生涯、伦理）：悬念 + 站队 + 盲盒 + 复盘。
- 认知纠偏类（批判思维、归因、舆论）：悬念 + 反转 + 身份 + 复盘。
- 概念/结构类（社会学、经济、管理）：悬念 + 盲盒 + 身份 + 反转 + 复盘。
- 情感/鉴赏类（语文、音乐、心理）：悬念 + 身份 + 反转 + 复盘。

### 5.6 输出目录与命名

**所有产物放进同一个课题子目录**，目录名 `教案-<课题>/`。文件名只用课题名，
**不要加“高职版 / 职场版 / 45 分钟版”这类后缀**；学段、课时、班级等信息写在文档内的
元信息行里，不写进文件名。

```
教案-<课题>/
├── 教案-<课题>.docx           教师用（投屏内容以黄底标出）
├── 投屏PPT-<课题>.pptx        上课投屏
├── 打印材料包-<课题>.docx      一份打完所有课堂实物材料
├── 材料清单-<课题>.docx        照单打印
└── 源文件/                     中间源（不交交付）
    ├── 教案-<课题>.md
    ├── 材料清单-<课题>.md
    └── 配套材料/材料N-<名称>.md
```

**交付区只放 .docx 与 .pptx**：同一份内容不要同时留 md / docx / pdf 三种格式。
Markdown 是生成用的源，统一收进 `源文件/`；**PDF 默认不生成**，只有当用户明确
要“打印用的 PDF / 投屏用的 PDF”时才额外导。

同一课题确实需要区分版本时，用**目录**区分（如 `教案-<课题>-v2/`），
不要把版本号或受众塞进每一个文件名。

步骤：

1. 建课题子目录与 `源文件/`，先把教案写成 Markdown：`源文件/教案-<课题>.md`。
2. 在课题目录内转 Word：

```bash
cd "教案-<课题>"
python3 ~/.codewhale/skills/teaching-plan/scripts/make_docx.py "源文件/教案-<课题>.md" \
  -o "教案-<课题>.docx" \
  --title "教案：<课题>" --subtitle "综艺思维六机制 · <课时>" \
  --meta "适用对象：<学段/课程>"
```

3. **排版参照**：脚本已内置 kami 设计规范（墨蓝强调色、暖调灰、三线表、页眉页码、留白节奏），细则见 `references/word-layout.md`。
   - **若 kami 技能可用**：先读 `~/.agents/skills/kami/references/tokens.json` 与 `CHEATSHEET.md`，用其色板与字号层次校准本次排版。注意 **kami 输出 HTML/PDF，不产 Word**——所以“优先用 kami”落地为采用它的设计规范；若用户另需 PDF 或网页版，再走 kami 的 `long-doc` / `one-pager` 模板。
   - **若 kami 不可用**：直接用内置模板（就是同一套规范）输出，不依赖任何外部技能。
   - 想要更贴近 kami 的衬线视觉：加 `--style kami`（标题仓耳今楷 / 正文思源宋体，需本机装有该字体）；也可用 `--font-title` / `--font-body` 指定字体。
4. 交付时报告：课题目录路径与其他产物清单、课时假设、案例来源（联网的标出后端与链接）、需要老师按本校学情微调之处。

> 排版校验：生成后用 `python-docx` 回读确认段落/表格/页眉，必要时 `soffice --headless --convert-to pdf` 确认能正常打开。**视觉（三线表、色条、分页）需在 Word/WPS 里打开确认**，脚本不能替代人眼。

> 环境注意：若 `write` 工具在当前卷（外挂盘 / 网络盘 / 共享目录常见）报 `Operation not supported`，改用 shell heredoc 写文件即可，内容与流程不变：
> `cat > "教案-<课题>.md" <<'EOF' ... EOF`。make_docx.py 本身不依赖 write 工具。

### 5.6.1 教案标题区只放信息，不重复方法论

教案的标题区（`--title` / `--subtitle`）**不要再写“综艺思维六机制”这类教学法表述**——
正文的“机制地图”表已经完整说明了用了哪几种机制，标题区重复一遍没有信息量。
标题区应当只放：课题名 + 适用对象 / 课时 / 班级规模。

生成示例（**不传 `--subtitle`**）：

```bash
python3 ~/.codewhale/skills/teaching-plan/scripts/make_docx.py "源文件/教案-<课题>.md" \
  -o "教案-<课题>.docx" --title "教案：<课题>"
```

（注：投屏 PPT 的封面**更不能**写教学法名——见 §5.8，那是学生要看的。）

### 5.7 投屏标记（教案里必须标出来）

需要投屏给学生看的内容，在教案 Markdown 里用 `:::slide` 块包裹，生成 Word 时会渲染为
**浅黄底纹 + 金色左竖条 + “▶ 投屏”标签**，教师一眼就能分清“哪些是要放出去的、哪些是自己看的”。

```markdown
:::slide 环节一｜悬念开场
（页面标题行）
正文要点
---
（块内 --- 表示同组下一页投屏）
提问：这一页要抛给学生的唯一问题
:::
```

- 每个 `:::slide` 块对应 PPT 的一组页面，块内 `---` 分页。
- 以“提问 / 追问”开头的行，在 Word 里以墨蓝加粗显示，在 PPT 里是墨蓝底白字的提问框。
- **不要把整段讲解都标成投屏**：只标学生真正要看的那几行。

> **投屏标签不得出现机制名**（这是最容易犯的错）。PPT 标签面向学生，
> 写上“悬念开场 / 反转 / 身份 / 站队 / 盲盒 / 复盘”等于把教学策略提前公告给学生，
> 悬念当场失效。标签要用**学生视角的活动语言**：
>
> | 环节（教案里写的） | 投屏标签（学生看到的） |
> |---|---|
> | 一 · 悬念开场 | 第一环节 · 开场 |
> | 二 · 反转 | 第二环节 · 读一份方案 |
> | 三 · 身份 | 第三环节 · 分组讨论 |
> | 四 · 盲盒 | 第四环节 · 抽一张卡 |
> | 五 · 讲授 | 第五环节 · 讲清楚 |
> | 六 · 站队 | 第六环节 · 做选择（第 N 次） |
> | 七 · 复盘 | 第七环节 · 回到最开始 |
> | 八 · 练习 | 第八环节 · 动手写一份 |
>
> 机制名只允许出现在教案（教师用）里。`make_pptx.py` 内置了兑底替换：
> 标签里出现机制词会自动换成中性说法并在 stderr 报告，不要依赖它。

### 5.8 投屏 PPT

```bash
cd "教案-<课题>"
python3 ~/.codewhale/skills/teaching-plan/scripts/make_pptx.py "源文件/教案-<课题>.md" \
  -o "投屏PPT-<课题>.pptx" --title "<课题>" --subtitle "<班级 / 场合，如：2026 级 · 第一次项目课>"
```

> **封面副标题只写学生视角的信息**（班级、场合、日期），**不写“综艺思维六机制”“90 分钟”
> 这类教学法或备课信息**——封面是给学生看的，写上“综艺思维六机制”等于一开课就告诉学生
> “这节课是用综艺套路设计的”。`make_pptx.py` 检测到这类词会直接省略副标题并告警；
> 宁可不写副标题，也不要写教学法名。

视觉参照 kami（羊皮纸底、墨蓝强调、村线层次）。编排规则详见
`references/slide-layout.md`，其中最关键的一条：

> **一页只放一个问题。** 悬念、反转、站队、盲盒类环节必须逐页推进，
> 一次只给一个提问；答案提前露出来，悬念就失效。只有总结/回顾页、
> 以及任务清单型内容（如练习六项要求）才允许一页列全。

### 5.9 打印材料包

教案里需要发到学生手上的材料（活动方案、章程草稿、卡片、学案、练习模板、
开场小纸条等），每一份写成 `源文件/配套材料/` 里的一个 `.md` 文件，然后合并：

```bash
cd "教案-<课题>"
python3 ~/.codewhale/skills/teaching-plan/scripts/make_pack.py 源文件/配套材料 \
  -o "打印材料包-<课题>.docx" --title "《<课题>》配套打印材料"
```

默认走**适配排版**（字号约 10pt / 页边距 1.4cm / 行距 1.3）。目标有两条：

- **每份材料正好占 1 页**（自动分页）
- **每页填充率 88~100%** —— 既不能挤在角落（字小、留白多），也不许溢出

#### 两个排版工具（写在材料 md 里）

**① 多列卡片：`:::cards`** —— 身份卡、干系人卡、小纸条这类重复小块，
竖着一列排既浪费页面又把字挤小。改用多列表格排布，**表格线就是裁切线**：

```markdown
:::cards 2 h=215
### 卡 A · 学校后勤处
内容……
---
### 卡 B · 品牌方区域经理
内容……
:::
```

- 第一个数字是列数（卡片类建议 2 列）
- `h=` 是**每行最小高度（pt）**，用来把卡片撑到整页；写大了会溢出
- 块内 `---` 分隔每张卡，`###` 开头的行渲染为卡片标题

**② 精确间距：`:::gap`** —— 纯文字材料（项目简介、练习表）要撑满一页时，
在段落之间插入固定高度的空白：`:::gap 34`（单位 pt）。

#### 调参流程（每份新材料都要走一遍）

1. 生成 → 转 PDF → 量每页的填充率与是否溢出
2. **溢出**：减小 `h=` / `:::gap`，或精简该份材料 1~2 行
3. **未满**（<88%）：加大 `h=` / `:::gap`
4. 反复到六份（或若干份）材料都落在 88~100% 为止

```bash
soffice --headless --convert-to pdf --outdir /tmp 打印材料包-<课题>.docx
# 再用 pdfplumber 取每页 words/rects/lines 的 top、bottom，与页边距比较
```

> 注意：量填充率时要**把表格线和矩形也算进去**，只看文字边界会低估（卡片行高撑开的空间量不到）。

#### 小纸条 / 小卡片类材料：优先选不需要裁剪的方案

需要“每人一张、写点东西、收走、再发回”的小纸片（开场纸条、投票条、认领卡等）：

> **默认用便利贴（约 76×76mm），不要打印纸条。** 老师买一叠即可，无需打印、无需裁剪，
> 大小刚好写一句话；还能让学生写好贴在桌面或黑板上，形成“全班第一印象墙”，
> 环节七的对比效果反而更强。教案与材料清单里写“用便利贴”，这一份材料**不进材料包**；
> 纸质版只作为退路，源文件命名以 `_` 开头（`make_pack.py` 会自动跳过），
> 例如 `_备用-材料4-开场小纸条（没有便利贴时打印）.md`。

确实无法准备便利贴时，按下面的顺序退：

1. **学生自备纸**（撕半张作业纸），或直接用学案的预留栏（写好折角压住）。
2. **打印**：单张做成 **≥ A6（约 105×148mm）**，一页最多 **4 张**
   （`:::cards 2` 两行，一刀横 + 一刀竖 = 4 张）。
   **不要一页铺 8 张**——那样每张只有名片大小，写不下字，还要裁 3+1 刀。

> 判断标准：**裁剪次数 × 单张面积**。宁可多打几页纸，也不要让老师和学生
> 在上课前花五分钟剪纸——那段时间本该用来进入课堂。

#### 其他硬规定

- **材料上不叠加任何元信息**：不要"【需打印】材料 N""共 N 份材料""请按《材料清单》打印分发"
  之类的话，**也不要页眉和页码**（`make_pack.py` 已默认关闭）。
- `--compact` 只在单份材料内容极多、适配排版也放不下时使用；`--standard` 字体最大但常超页。
- **子材料必须写实**：卡片要真的能剪，草稿要真的像一份草稿，模板要真的是空表格。
- 反面教材类文档（如"看起来很齐全、实际缺三项"的方案）同样是子材料，必须写出来。

### 5.10 材料清单

单独输出 `教案-<课题>/材料清单-<课题>.docx`（源在 `源文件/材料清单-<课题>.md`）。
逐条写：材料编号、名称、对应环节、用途、**建议打印份数**、纸张规格、单双面、是否需裁剪，
并给出一句**打印量速算**（如“双面 2 张 A4 打完全部材料”）。

## 6. 联网检索规范（当需要真实案例/数据时）

任何联网搜索**必须优先走百度 Key**：

```bash
~/.codewhale/bin/cwsearch "查询词" --top-k 8
```

- 退出码 `0`：stdout 为 JSON（`results[{rank,title,url,date,content}]`），引用时**必须使用其中的真实 `url` 与 `date`，不得编造链接或日期**。
- 退出码 `2`（配额耗尽）：改用内置 `Web` 搜索兜底，并在回答中注明"百度额度已用尽，本次结果来自 DeepSeek"。
- 退出码 `3`（网络/密钥/参数错误）：同样用内置 `Web` 兜底，并说明原因。
- 百度成功时**不得**改用其它后端；不同后端的结果不得混说成同一来源。
- 搜索目标优先级：真实新闻事件/权威数据 > 学科经典案例 > 网络热梗（慎用，须与主题强相关）。
- 案例不要求"新"，但要求"真"：**宁可用旧的经典案例，也不用编造的新案例**。无法核实的素材一律标注"待核实"。

## 7. 交付前校验清单

- [ ] 每个环节都有**关键提问**和**逐轮加条件/加信息**的推进动作。
- [ ] 复盘环节**确实回到开场的问题/预测**，形成闭环。
- [ ] 案例、数据、引用的来源真实可溯；无编造。
- [ ] 时长加总与课时一致。
- [ ] 教案可直接上课：教师拿到就能照着走，不需要再补齐大量细节。
- [ ] 未用满六机制时，已说明为什么。
- [ ] Word 已生成且回读校验通过（段落数、三线表、页眉标题、页码）；已在交付说明中区分"结构已校验"与"视觉待你确认"。
- [ ] 教案中**提到的每一份子材料都有对应文件**（方案、草稿、卡片、学案、练习模板），无“凭空引用”。
- [ ] 需要投屏的内容已用 `:::slide` 标记，并在教案 Word 里呈现为黄底；已生成投屏 PPT。
- [ ] 投屏 PPT 遵守“一页一问题”；逐条揭晓 / 逐轮加条件已拆成多页，没有把答案提前露出来。
- [ ] 需要打印的材料已汇入打印材料包并标注「【需打印】」；`材料清单` 已单独输出且份数可执行。
- [ ] 全部产物都在**同一个 `教案-<课题>/` 子目录**内；交付区只有 `.docx` 与 `.pptx`，
      Markdown 源已收进 `源文件/`，没有多余的 md / pdf 副本。
- [ ] 文件名**不含“XX版”“XX专用”之类后缀**；学段、课时写在文档内的元信息行。
- [ ] 投屏 PPT 的标签里**没有出现机制名**（悬念/反转/身份/站队/盲盒/复盘）。

      文字类用 `:::gap` 撑满；材料上无“【需打印】”“共 N 份”等元信息文字，**也没有页眉和页码**；

- [ ] 教案开头有“跨环节动作提醒”表；发纸条/发材料/收回/抽签等动作已在**发生的那一刻**用 `★` 标明，

- [ ] **每个发放类动作都给出了教师指导语**（写什么/多久/要不要署名/怎么交），
      对需要保密的用途给了不泄底的由头；没有出现“只写发材料、不写对学生说什么”的情况。
- [ ] 板书 / PPT 建议已写在教案中，且与实际的 PPT 页面一致。

## 8. 禁忌

- 不要把课变成"活动堆砌"：加视频、加游戏、加投票不等于有认知节奏。
- 不要娱乐化、不要为反转而反转、不要制造与知识点无关的冲突。
- 不要编造案例、数据、新闻。
- 不要跳过复盘；不要用"今天学了三个知识点"收尾。
- 不要照抄原帖案例而不适配本次知识点——机制是骨架，案例必须长在本次内容上。
